# Новорічний подарунок

Консольний застосунок на Java для лабораторної роботи №1 з ООП.

Моделює ієрархію цукерок та інших солодощів, збирає з них дитячий новорічний
подарунок, обчислює його вагу, сортує солодощі за обраним параметром і шукає
цукерку за діапазоном вмісту цукру.

## Можливості

- Ієрархія солодощів з наслідуванням та поліморфізмом
- Збирання подарунка та обчислення його загальної ваги
- Сортування солодощів у подарунку (за назвою, вагою або вмістом цукру)
- Пошук солодощів за діапазоном вмісту цукру
- Завантаження солодощів з текстового файлу
- Покриття коду unit-тестами (JUnit 5, Mockito)

## Технології

- Java 17
- Maven
- JUnit 5
- Mockito

## Структура проєкту

```
src/main/java/com/newyeargift
├── Main.java                  точка входу
├── model
│   ├── sweet                  ієрархія солодощів (Sweet, Candy, ...)
│   └── gift                   подарунок (Gift)
├── service                    сортування та пошук солодощів
└── data                       читання солодощів з файлу ресурсів

src/test/java/com/newyeargift  unit-тести, що віддзеркалюють структуру main

src/main/resources/sweets.txt  файл з початковими даними про солодощі
```

## Ієрархія солодощів

```
Sweet (abstract)
├── Candy (abstract)
│   ├── ChocolateCandy
│   └── Caramel
└── Cookie
```

## Запуск

```
mvn compile exec:java -Dexec.mainClass="com.newyeargift.Main"
```

Або запустити клас `Main` безпосередньо з IntelliJ IDEA.

## Запуск тестів

```
mvn test
```

## Формат файлу з даними

Кожен рядок `src/main/resources/sweets.txt` описує одну цукерку у форматі
`тип;назва;вага;цукор%;...`, де набір останніх полів залежить від типу:

```
CHOCOLATE;Milk Delight;12;45;milk;30
CARAMEL;Toffee;8;70;vanilla;false
COOKIE;Choco Bite;20;35;true
```

- `CHOCOLATE` — назва, вага (г), вміст цукру (%), смак, вміст какао (%)
- `CARAMEL` — назва, вага (г), вміст цукру (%), смак, `true`/`false` (тверда чи ні)
- `COOKIE` — назва, вага (г), вміст цукру (%), `true`/`false` (з начинкою чи ні)

Рядки, що починаються з `#`, та порожні рядки пропускаються.
